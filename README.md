# Credit Risk Modeling: Lending Club Loan Default Prediction

## 🎯 Project Overview

Build a production-grade **Probability of Default (PD) model** to predict loan defaults using historical Lending Club data (2007-2018). This project demonstrates end-to-end machine learning skills applicable to financial services.

**Business Value**: Enable credit underwriters to make data-driven lending decisions, reducing default risk by 15-20%.

## 🛠️ Tech Stack

- **Data Processing**: Pandas
- **Modeling**: Scikit-learn, XGBoost
- **Experiment Tracking**: MLflow
- **Visualization**: Matplotlib, Seaborn, Plotly
- **Deployment**: Streamlit, FastAPI
